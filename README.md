## 课程项目

学生原则上3人一组，在课程组织内使用本组私有仓库完成贯穿项目。三个岗位按三轮迭代轮换：

- A：产品经理＋测试；
- B：需求分析师＋架构师；
- C：项目经理＋程序员。

## 成绩构成

- 平时成绩60%：五次实践；
- 期末成绩40%：期末大作业20%＋个人课程工作陈述20%；
- 证据形态：GitHub制品60%＋课堂检查与个人陈述40%。

## 隐私与学术诚信

本公共仓库不存放学生名单、学号—账号映射、成绩或小组私有代码。学生使用资料、同伴、教师示例或AI辅助时，须按课程规则披露并能够解释、修改和验证最终成果。
